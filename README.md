# Giperion

Локальный ИИ-собеседник: собственное нейросетевое ядро, правила, память,
навыки и оконный интерфейс. Проект не оборачивает готовую LLM — модели
классификатора и генератора написаны вручную и обучаются на данных проекта.
Внешние модели OpenCode подключаются опционально как помощники.

## Что умеет

- понимать 77 намерений (1775 размеченных фраз) гибридным word/char-CNN;
- генерировать ответы собственной seq2seq-моделью с вниманием Бахданау;
- вести диалог по правилам: приветствия, время, математика, профиль,
  обучение новым фразам, архивы памяти, системные команды;
- читать текстовые файлы, искать в интернете, звать внешнюю модель,
  когда локальное ядро не уверено;
- развиваться как персонаж: опыт, уровни, ранги, версия ядра;
- разделять умения исполнительного ядра и активной модели ИИ;
- передавать новой модели скрытую историю текущего чата;
- готовить конференцию из нескольких моделей-участников;
- запускать параллельный совет моделей с общей историей чата;
- пускать в совет не больше трёх моделей с лучшей репутацией и присваивать
  им должности «Сенатор 1–3»;
- показывать у сенаторов значок человека за трибуной в закладке
  «Конференция»;
- настраивать отдельные цвета, размеры и стили шрифта для трёх сенаторов;
- ставить Гипериона первым в совете, остальных — по убыванию репутации;
- показывать короткие ники моделей в чате и карточке модели;
- помечать в чате участника, который воздержался от ответа;
- не смешивать режимы: выбор модели выключает конференцию, а при
  включении конференции активная модель добавляется в совет;
- скрывать недоступные в России и нерабочие модели OpenCode;
- показывать ошибки внешних моделей в поле системных сообщений и отвечать
  локальным ядром, если конференция не смогла собрать ответы;
- настраивать отдельный цвет, размер и стиль шрифта внешних моделей;
- показывать основные параметры компьютера в закладке «Система»;
- работать в консоли и в окне с несколькими независимыми чатами.

## Требования

- Python 3.13;
- видеокарта NVIDIA для обучения (проект проверен на RTX 5080, CUDA 12.8);
  инференс работает и на CPU, но медленнее;
- для внешних моделей — запущенное приложение OpenCode.

## Установка

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1

# CUDA-сборка PyTorch под свою видеокарту (пример для CUDA 12.8)
pip install torch --index-url https://download.pytorch.org/whl/cu128

pip install -r requirements.txt
# для тестов:
pip install -r requirements-dev.txt
```

## Запуск

```powershell
python gui.py    # оконный интерфейс
python main.py   # консольный вариант
```

Для консоли Windows полезно заранее включить UTF-8:

```powershell
$env:PYTHONIOENCODING='utf-8'
```

## Тесты

```powershell
python -m pytest -q
```

Тесты не требуют видеокарты, сети и запущенного OpenCode: внешние вызовы
подменяются заглушками, данные пишутся во временные каталоги. Оконные
проверки идут в режиме `offscreen`.

## Данные и модели

Исходные данные:

- `data/intents.json` — намерения: тег, фразы, ответы;
- `data/conversations.json` — история диалогов (не коммитится);
- `data/unknown_messages.json` — накопитель непонятых фраз;
- `data/chat_contexts/` — скрытые выжимки открытых чатов (не коммитятся);
- `data/models.json` — каталог моделей OpenCode и собственного ядра;
- `data/personality_matrices.json` — каталог будущих личностей.

Сборка датасета и обучение:

```powershell
python -m training.build_dataset     # classification.json, pairs.json
python -m training.tokenizer         # models/tokenizer.json
python -m training.char_tokenizer    # models/char_tokenizer.json
python -m training.train_charcnn --full   # models/hybrid.pt
python -m training.train_seq2seq     # models/seq2seq.pt
```

Цикл дообучения на непонятых фразах:

```powershell
python -m tools.label_unknown        # черновик data/unknown_labels.json
python -m tools.apply_unknown        # проверенная разметка → intents.json
python -m training.build_dataset
python -m training.train_charcnn --full
python -m training.train_seq2seq
```

`tools/check_neural.py` — быстрый дымовой тест моделей.
Ответы внешних моделей в обучение не попадают: у сообщений есть поле
`model`, и `training/build_dataset.py` отбрасывает чужие ответы.

## Структура

```
app/
  core/        маршрутизация ответов, модели, состояние диалога, эволюция
  language/    намерения, обучение фразам, нормализация текста
  memory/      история, профиль, архивы, системные подтверждения
  skills/      калькулятор, время, чтение файлов, поиск в интернете
  storage/     единое чтение и атомарная запись JSON
  ui/          окно и его слои: виджеты, диалоги, аватар, транскрипт, чаты
gui.py         тонкий вход: собирает окно из app/ui
main.py        консольный вход
training/      свои модели и тренеры
tools/         разметка, миграции данных, генерация ассетов, оценка
tests/         pytest
data/          данные и настройки
models/        чекпоинты и токенизаторы
```

Крупные домены разделены на модули: каталог моделей
(`model_catalog`/`model_settings`/`model_custom`/`model_stats`), системные
команды (`system_commands`/`confirmations`), обучение
(`learning_commands`/`learning_presenter`), поиск (`skills/search/`) и
загрузка нейросети (`neural_loader`). Маршрутизация ответа собрана в
`app/core/chat_pipeline.py` (`STAGES`), а `chatbot.py` остаётся тонким
оркестратором. Исторические имена
`model_registry`, `system_handler`, `learning_handler` и `web_search`
оставлены фасадами для совместимости импортов; `neural_engine` сохраняет
класс движка, пороги уверенности и кэш моделей.

Данные и настройки хранятся в JSON. Запись идёт через
`app/storage/json_store.py`: сначала временный файл, затем атомарная замена,
поэтому сбой посреди сохранения не портит прежние данные.

## Настройки

- `data/window_settings.json` — шрифт, цвета, размеры групп, стили,
  печать, модули;
- `data/model_settings.json` — активная модель и компаньоны;
- `data/personality_settings.json` — выбранная личностная матрица;
- `data/model_stats.json` — обращения и расход токенов.

Секреты внешних моделей в проекте не хранятся: адрес и пароль локального
сервиса OpenCode читаются из пользовательских файлов приложения.

## Ограничения

- личностные матрицы пока влияют только на интерфейс, не на ответы;
- генерация кода (этап 6) не реализована;
- внешние модели требуют запущенного OpenCode и используют его
  экспериментальные эндпоинты;
- seq2seq-small обучен на небольшом датасете: смысл ответа устойчив,
  дословное совпадение с эталоном — нет;
- поиск в интернете отдаёт заголовки и короткие описания, а не пересказ
  полных страниц.
