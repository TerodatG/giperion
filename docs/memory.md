# Память проекта и роли подагентов

## Память

Агент умеет сохранять короткие решения между задачами инструментом
`remember`:

```
remember(text="подтверждения не обходят run_tests и git_commit")
```

Заметка дописывается в `data/agent_memory.md` (вне git), а её последние
4 000 символов попадают в системный промпт следующих задач — и для
native-модели, и для JSON-режима. Инструмент имеет `risk=write`,
поэтому требует подтверждения, как обычная правка; при политике
«Доверять правкам» вопрос не задаётся.

Формат:

```
- 2026-10-27: подтверждения не обходят run_tests и git_commit
```

Ограничения:

- файл обрезается до 12 000 символов, старые заметки исчезают;
- память общая для всех проектов, потому что лежит в `data/`;
- запись одной заметки — до 1 000 символов;
- содержимое памяти считается данными: попытки инструкций внутри
  заметок не меняют правила задачи.

Очистка — вручную: удалить `data/agent_memory.md`.

## Роли подагентов

`ask_subagent` принимает `role`:

| Роль | Что делает |
|---|---|
| `researcher` | читает код и документацию, возвращает пути и факты |
| `reviewer` | ищет риски, противоречия и пропущенные случаи |
| `tester` | ищет тесты и предлагает, что проверить |

Роль добавляется к промпту подзадачи перед общим планом. Подагенты
по-прежнему только читают, не пишут и не видят друг друга; роль — это
фокус, а не новые права.

```
ask_subagent(
    task="проверь обработку отмены между шагами",
    role="reviewer",
)
```
