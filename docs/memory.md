# Память проекта и роли подагентов

## Память

Агент умеет сохранять короткие решения между задачами инструментом
`remember`:

```
remember(text="подтверждения не обходят run_tests и git_commit")
```

Заметка дописывается в память проекта
`data/agent_memory/<проект>-<хеш>.md` (вне git), а её последние
4 000 символов попадают в системный промпт следующих задач этого проекта
— и для native-модели, и для JSON-режима. У каждого корня проекта свой
файл, поэтому заметки разных проектов не смешиваются. Инструмент имеет
`risk=write`, поэтому требует подтверждения, как обычная правка; при
политике «Доверять правкам» вопрос не задаётся.

Формат:

```
- 2026-10-27: [arch, db] (до 2026-11-26) хранилище на sqlite
```

Поля после даты необязательны: теги в квадратных скобках и срок жизни
`(до ГГГГ-ММ-ДД)`. Истёкшие заметки не попадают в промпт и удаляются
`prune()`.

Возможности:

- теги и поиск по тексту/тегам;
- дедупликация: повторная заметка возвращает существующую строку;
- TTL на заметку, очистка истёкших;
- импорт и экспорт в Markdown;
- секреты вырезаются редактором до записи;
- заметка с тегом `pin` не вытесняется при переполнении: она идёт
  блоком «Закреплено» перед остальными.

Ограничения:

- файл обрезается до 12 000 символов, старые заметки исчезают;
- запись одной заметки — до 1 000 символов, тегов — до 8;
- содержимое памяти считается данными: попытки инструкций внутри
  заметок не меняют правила задачи.

Очистка — вручную: удалить файл проекта в `data/agent_memory/` или
нажать «Очистить» в окне памяти.

В «Провайдере» кнопка **«Память…»** открывает редактор заметок текущего
проекта: можно посмотреть, дописать или очистить память без ручной
правки файла.

## Роли подагентов

`ask_subagent` принимает `role`:

| Роль | Что делает |
|---|---|
| `researcher` | читает код и документацию, возвращает пути и факты |
| `reviewer` | ищет риски, противоречия и пропущенные случаи |
| `tester` | ищет тесты и предлагает, что проверить |

Роль добавляется к промпту подзадачи перед общим планом. Подагенты
по-прежнему только читают, не пишут и не видят друг друга; роль — это
фокус, а не новые права.

```
ask_subagent(
    task="проверь обработку отмены между шагами",
    role="reviewer",
)
```
