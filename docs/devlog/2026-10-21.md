# DEVLOG 2026-10-21

## 2026-10-21 — Этапы 0–3: инфраструктура, датасет, классификаторы, seq2seq

**Контекст**

- Цель: своя нейросеть «с нуля» — код моделей пишем вручную, PyTorch как вычислительный движок.
- Оба варианта важны: и понять механику, и получить живого бота.
- Железо: NVIDIA RTX 5080 (16 ГБ, Blackwell), Python 3.13.14.
- Данные: `data/intents.json` — 77 намерений, 1314 фраз (теги частично английские:
  cooking, geology, meteorology…); `data/conversations.json` — шумная история ~440 сообщений.

**План этапов**

0. Инфраструктура: PyTorch + CUDA.
1. Датасет: скрипт сбора, свой токенизатор.
2. Классификатор намерений (своя модель: embedding → свёртки → MLP).
3. Генеративная seq2seq модель с механизмом внимания (свой код).
4. Интеграция в `chatbot.py` с fallback на правила.
5. Цикл роста: непонятые фразы → разметка → дообучение.

**Выполнено**

- Этап 0: PyTorch 2.11.0+cu128 установлен, `torch.cuda.is_available()=True`,
  GPU видна: NVIDIA GeForce RTX 5080.
- Этап 1: `training/build_dataset.py` → `data/dataset/classification.json`
  (1314 примеров, 77 классов), `pairs.json` (8737 пар), `unlabeled.json` (3);
  `training/tokenizer.py` → `models/tokenizer.json` (словарь 2309 токенов:
  `<pad>`=0, `<unk>`=1, `<sos>`=2, `<eos>`=3); нормализация — `normalize_message`.
- Этап 2 v1: TextCNN (`models/classifier.pt`, 496 тыс. параметров) — val=0.189
  при train=1.000 (переобучение).
- Диагностика v1 (`training/diagnose_classifier.py`): 82% проверочных текстов содержат
  слова, не виденные в обучении (точность 11.1% на новых vs 54.2% на знакомых).
- Этап 2 v2: исправления — стратифицированное разделение по классам, аугментация EDA
  (перестановка/удаление слов ×2, только после split), AdamW (wd=1e-4), label smoothing 0.1,
  исправлен баг: max-pool «слышал» паддинг → masked pooling (`masked_max_pool` в
  `model_classifier.py`), 30 эпох. Результат: val=0.231 (train=0.974);
  знакомые слова 68.0%, новые 12.4%.
- Этап 2 v3 (char-CNN): символьный токенизатор `training/char_tokenizer.py`
  (словарь 82 символа, `models/char_tokenizer.json`, MAX_CHAR_LEN=96),
  гибридная модель `training/model_charcnn.py` — word-CNN + char-CNN
  (`models/hybrid.pt`, 653 тыс. параметров), тренер `training/train_charcnn.py`,
  диагностика `training/diagnose_hybrid.py`. Результат: **val=0.300**;
  знакомые слова 80.0%, новые 18.1% — символьная ветка обобщает
  (морфемы, опечатки, похожие корни).
- Этап 3: seq2seq с собственным вниманием Бахданау (`models/seq2seq.pt`,
  2 млн параметров): token acc 0.779, exact match 0.047, но генерации семантически
  корректные (пример: «кухня» → «я не ем, но с удовольствием обсужу еду!»).
  Урок: exact match обманчив — у каждой фразы ~7 допустимых ответов.
- Этап 4: интеграция в бота.
  - `app/core/neural_engine.py` — inference-движок: ленивая загрузка моделей,
    пороги CONFIDENCE_THRESHOLD=0.45 (ниже — работают правила) и
    GENERATION_THRESHOLD=0.6 (выше — отвечает seq2seq, между — готовый ответ
    намерения). Без моделей/PyTorch бот работает как раньше (движок → None).
  - `app/core/chatbot.py` v033: приоритеты — служебные хендлеры → точные правила
    (вкл. выученное пользователем!) → нейросеть → difflib-уточнение → unknown.
    Порядок исправлен после регрессии в 2 тестах (нейросеть перехватывала
    выученные фразы — точное знание важнее генерации).
  - Финальный train гибрида на всём датасете: `python -m training.train_charcnn --full`
    (2276 примеров с аугментацией, без val — `models/hybrid.pt` перезаписан).
  - `tools/check_neural.py` — дымовой тест: диагноз + ответ бота по фразам.
  - `training/tokenizer.py` v002: decode больше не приклеивает тире (— –).
  - Итог: 51 тест проходит; примеры — «зарплата» → work (0.91),
    «Какая погода сегодня?» → сгенерированный ответ, «люпапупу» → unknown.
- Расширение датасета перефразировками.
  - `data/phrase_candidates.json` — 185 кандидатов для 12 ключевых классов:
    сгенерированы языковой моделью, проверены человеком (отсеяно 8 дублей,
    переименованы 2 несуществующих тега: goodbye → farewell, jokes → joke).
  - `tools/add_candidates.py` — пакетное слияние через сервис обучения
    (`add_phrase_to_category`): дедупликация по normalize_message по всем
    категориям, идемпотентный повторный запуск. Влито 181 фраза.
  - Датасет: 1314 → 1495 примеров; пар: 8737 → 10095; словарь: 2309 → 2419.
  - Обе модели переобучены с нуля: гибрид (2813 примеров с аугментацией,
    667k параметров), seq2seq (10095 пар, token acc 0.784, 2.1M параметров).
  - Итог: «расскажи интересный факт» — уверенность fact 0.28 → **0.98**
    (генерирует факты!); новые фразы пойманы: «ржачная тема есть?» → joke
    (0.93), «топ книг назови» → books (0.96), «ну как сам?» → how_are_you
    (0.93). 51 тест проходит.
  - Урок: перед генерацией кандидатов проверять реальный список тегов
    (в intents.json теги неочевидны: farewell, joke, humor, smalltalk).
- Этап 5: цикл дообучения на непонятых фразах.
  - `tools/label_unknown.py` — разбор накопителя с подсказкой нейросети:
    предлагает действие (`add` с тегом, `trash` для мусора, `skip` если модель
    не уверена) и пишет черновик `data/unknown_labels.json` для проверки.
    Фразы, уже существующие в intents.json, помечаются `trash`.
  - `tools/apply_unknown.py` — применяет черновик: `add` вливает в intents через
    сервис обучения и убирает из накопителя, `trash` просто убирает, `skip`
    оставляет. Накопитель чистится через `remove_unknown_messages` (уже был).
  - Сквозная проверка: «хочу завести дракона» (модель сомневалась, food 0.25)
    → размечено в `animals` → переобучение → уверенность 0.93. Мусор
    («абракадабра») отсеян как `trash`.
  - Переобучение: 1496 примеров, 10101 пара; гибрид и seq2seq обновлены.
  - «чо как» бот понял сам (how_are_you) — доказательство работы обобщения.
  - Цикл замкнут: общение → накопитель → разметка → intents → переобучение.
    51 тест проходит.
- Оконный интерфейс.
  - `gui.py` — окно из `main_window.ui` (PySide6, `QUiLoader`) соединено с ботом:
    история чата, поле ввода (Enter — отправка, Shift+Enter — перенос строки),
    кнопка «Отправить», панель «Параметры ИИ-ядра» с живыми данными из
    `get_characteristics()` и обновлением после каждого сообщения.
  - Логика обработки команд такая же, как в `main.py`: выход, системные команды
    («Гиперион, система: …»), подтверждение pending_action, `get_response` +
    запись истории. Цветовое различие: пользователь, бот, система.
  - Запуск: `python gui.py` (консольный вариант остаётся — `python main.py`).
  - Проверено в headless-режиме (offscreen): диалог, генерация, системные
    команды и панель ядра работают.
- Гиперион как развивающийся «персонаж».
  - `app/core/evolution_service.py` — опыт, уровни, ранги, динамические тип и
    версия. Пороги уровней растут экспоненциально (BASE 120, множитель 1.55):
    уровень 5 — 1041 опыта, 10 — 11048, 12 — 26850. Рост виден неделями,
    потолка нет. Опыт складывается из навыков, категорий знаний, сообщений и
    разобранных фраз, минус штраф за непонятые.
  - Ранги: Пробуждение → Новичок → Ученик → Собеседник → Знаток → Наставник →
    Мудрец. Тип ядра растёт вместе с уровнем: пробуждающийся → растущий →
    развитый → продвинутое → зрелое ядро (устаревшее «учебный» убрано).
  - Версия ядра привязана к уровню: поднимается на 0.1 каждые 3 уровня
    (уровень 1–3 → 0.1, 4–6 → 0.2, …).
  - `character_service.py` v002 собирает уровень, прогресс, разбивку опыта;
    `character_handler.py` v002 рисует прогресс-бар в консоли; `gui.py` —
    бар и разбивку в панели «Параметры ИИ-ядра».
  - Пример текущего состояния: уровень 3 «Новичок», 12%, версия 0.1,
    опыт 343 (навыки 165, память 181, непонятые −3).

  - Правая панель с кнопкой «Настройки» (вверху панели). По нажатию —

  - «Вид» — отдельное окно: слева кнопки-разделы «Размер шрифта» и
    «Цвет шрифта» (верхний раздел открыт по умолчанию), справа содержимое.
    Размер шрифта чата — 8–28. Цвет — для четырёх ролей: Система, Гиперион,

  - В окне «Вид» есть кнопка «Применить»: меняет шрифт и цвета сразу,
