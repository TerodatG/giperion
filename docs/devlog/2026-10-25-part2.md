## 2026-10-25 — без мигающей консоли при замерах

**Причина**

- Окно производительности опрашивает `nvidia-smi`. На Windows это
  консольная программа, и `subprocess.run` без скрытия окна каждый раз
  показывал чёрное окно консоли, похожее на PowerShell.

**Выполнено**

- Новый `shared/process_tools.py` с `hidden_process_options()`:
  - `CREATE_NO_WINDOW`;
  - `STARTUPINFO` с `SW_HIDE`.
- `performance_monitor.read_gpu_details()` запускает `nvidia-smi`
  со скрытым окном.
- `opencode_client._discover_url()` запускает `opencode-cli` так же,
  чтобы при обращении к внешним моделям консоль тоже не мигала.
- На не-Windows системах опции пустые, поведение не меняется.

**Проверено**

- `python -m pytest -q` — **214 passed**.
- `python -m compileall -q gui.py main.py giperion terminal shared tests tools` — ok.
- Новый тест проверяет `CREATE_NO_WINDOW` и `SW_HIDE`.
