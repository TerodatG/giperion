# 2026-10-27 · терминал: аудит, память, API, MCP и DAG

Продолжение работы по 20 пунктам. Модель Giperion вынесена в `model/` и
исправляется отдельно; здесь — только терминал и его границы.

## Что вошло

- **Память проекта**: файл на каждый корень в `data/agent_memory/`,
  теги, TTL, дедупликация, поиск, импорт/экспорт, редакция секретов.
  `remember` пишет в память проекта, промпт получает её из корня задачи.
- **Аудит**: события `run.start/finish/error`, `approval`, `denied`,
  `tool`; секреты в payload вырезаются. `--search`, подписанный экспорт,
  `--prune N` с архивом и пересборкой активной цепочки.
- **API терминала**: `project` ограничен рабочей папкой, ответ содержит
  трейс шагов; журнал `data/agent_api_calls.jsonl`; лимит 30 запросов в
  минуту; токен с правами 0600.
- **Шаги и бюджет**: пауза/продолжение задачи, предупреждение при 80 %
  лимита токенов или стоимости.
- **Инструменты**: `dry_run` для `run_command` и `run_tests`.
- **Знания**: импорт HTML, DOCX и PDF (PDF через необязательный
  `pypdf`), дедупликация по SHA-1, теги и дата в шапке.
- **Браузер**: `wait_text` и `wait_url`, скачивание с лимитом, пути
  файлов в ответе.
- **MCP**: транспорты `http`/`sse`, Bearer-токен из `token_env`,
  общий `mcp_base` без цикла импорта, лимит ответа 1 МБ.
- **Автономность**: файл-пауза демона и вебхук о цикле.
- **Мульти-агентность**: `tools.agent_dag` — зависимости, уровни,
  пропуск потомков упавшей задачи, worktrees и слияние.
- **Плагины**: подпись обязательна по умолчанию, `--allow-unsigned`
  только для разработки.
- **Поставка**: `tools.backup_data` (zip, manifest, защита от
  traversal), отдельная Linux-джоба CI для модели, standalone-фикстуры
  модели.

## Второй заход

- **run_command/run_tests**: `exec_sandbox` — чистый env, мёртвый прокси,
  Job Object 1 ГБ/60 с; Python-команды идут в AppContainer при готовой
  песочнице, иначе — процесс. Настройка `command_sandbox`.
- **Повтор с шага**: `AgentJob.history_before`, кнопка «С шага…»;
  контекст откатывается, файлы — нет (честное предупреждение).
- **Хунки**: `diff_marks.hunks` и `apply_hunks` — частичное применение
  изменений; UI-выбор ещё впереди.
- **Аудит подтверждений**: `approval.request` до вопроса и `request_hash`
  в событии решения; хеш виден в панели.
- **Браузер**: cookies/localStorage в `data/agent_browser/profile.json`,
  подхватываются следующей задачей.
- **Индекс**: лимит фрагментов 4000 → 6000 с инвалидацией кеша, иначе
  новые файлы вытесняли `tools/setup_plugin_container.py` из выдачи.

## Третий заход

- **Вкладки браузера**: `new_tab`, `switch_tab`, `close_tab`; воркер
  возвращает текущую страницу, сессия запоминает её. Вынесено в
  `browser_tabs`, поля действий — в `browser_fields`, текст/скриншот —
  в `browser_page`.
- **Окно базы знаний**: поиск по смыслу, цитаты с файлом и строкой,
  добавление текста с тегами и безопасное удаление только внутри
  `knowledge/`. Кнопка «База знаний…» в «Провайдере».
- **Алерты**: `tools.agent_alerts` и `alerts.check` — доля успеха
  последних прогонов, порог, вебхук и код 2 для ночного CI.

## Четвёртый заход

- **PDF браузера**: скачанный файл разбирается `pypdf`, текст попадает в
  ответ рядом с путём.
- **Политика проекта**: `data/agent_policies.json`, окно агента читает
  её перед запуском; глобальная осталась в `agent_settings.json`.
- **Каталог плагинов**: `data/plugin_catalog.json` и
  `tools.plugin_catalog`, установка по имени через обязательную подпись.
- **Доступность**: accessibleName у поля задачи и кнопок агента.
