**Контекст**

- Задача: убрать рамку Windows и одеть окно по скриншотам Paradise Cracked:
  тёмный металл с заклёпками, фиолетовые светящиеся экраны, зелёный
  терминальный лог, красные кнопки.
- Текстуры не рисуем руками — генерируем процедурно и подключаем через QSS.

**Выполнено**

- `tools/generate_ui_skin.py` — генератор текстур в `assets/ui/`:
  `metal_tile.png` (шумная сталь с потёртостями), `panel.png` (плита с кантом,
  фаской и заклёпками), `panel_purple.png` (та же плита с фиолетовым экраном

  подставляются абсолютными путями (`border-image` 9-slice), панель ядра
  получает фиолетовый экран, чат — зелёный терминал со строчной текстурой,
  кнопки — металл с красной рамкой, скроллбары — бронзовые с красным наведением.
- `gui.py` v013 — безрамочный каркас.
  - `_build_window_shell()`: `FramelessWindowHint`, скрытые меню и статусбар,
    `centralwidget` заворачивается в `windowShell` с металлическим фоном.
  - `_build_title_bar()`: пульсирующий светодиод, знак ядра, «ГИПЕРИОН»
    с красным свечением (`QGraphicsDropShadowEffect`), версия ядра и кнопки
    свернуть/развернуть/закрыть.
  - Края окна тянутся через `QWindow.startSystemResize`, планка переносит окно

    зелёный → жёлтый → красный, верхний сегмент мерцает).
  - Подписи панелей «ОБРАЗ ГИПЕРИОНА» и «ТЕРМИНАЛ СВЯЗИ», размерный уголок
    в панели инструментов, окно центрируется при запуске.
  - Портрет вписывается в панель без искажений и растворяется по краям
    виньеткой; цвета текста переведены на зелёный терминал, плашка нового
    уровня — тёмно-фиолетовая.
- Окно «Вид» переведено на тёмную тему (активный раздел — фиолетовый).
- 51 тест проходит; вид проверен headless-скриншотом.

**Ключевой вывод**

- `QLabel` с pixmap возвращает `minimumSizeHint`, равный размеру картинки:
  анимированный кадр раздувал панель образа при каждой перерисовке. Лечится
  политикой `QSizePolicy.Ignored` плюс подменой `sizeHint`/`minimumSizeHint`
  и явным `setStretch` для содержимого панели.

**Ключевые выводы**

- Маленький датасет (~15 фраз/класс, слова-одиночки): модель запоминает, но не обобщает.
  Символьный уровень заметно помогает обобщению (+5.7 п.п. на незнакомых словах).
- Уверенность модели на ошибках низкая (0.07–0.36) — порог уверенности в связке
  с fallback на правила даст безопасный ансамбль.
- В продакшене классификатор обучится на ВСЕХ 1314 фразах — метрика на split
  оценивает обобщение на незнакомые слова, а не «все ли боту известные фразы он понимает».

**Конвенции**

- Консоль Windows: префикс `$env:PYTHONIOENCODING='utf-8'`, запуск модулями
  из корня проекта: `python -m training.…`.
- Стиль: русские комментарии/докстринги, заголовки `# Giperion/<файл> vNNN`.

**Дальше**

  на парах «задача → функция» и метрика pass@k через запуск сгенерированного

  - Меню правой кнопки для чата и поля ввода собираются вручную по-русски.
- `window_style.py` v003 — стиль кнопок планки, отступ подписей, бронзовый
  знак ядра вместо красного.

**Ключевой вывод**

- Подмена виртуальных методов на экземпляре (`widget.closeEvent = …`,
  `widget.keyPressEvent = …`) в PySide6 не перехватывает события от Qt:
  Enter не отправлял сообщение, а меню правой кнопки оставалось английским.
  Рабочее решение — `installEventFilter` (`ChatEventFilter`,
  `WindowCursorFilter`) с обработкой `QEvent.Close` / `ContextMenu` / `KeyPress`.
- Курсор растягивания у краёв нельзя ставить самому виджету-оболочке: дети
  наследуют его, и «стрелка в обе стороны» залипает на кнопках. Курсор
  считаем фильтром приложения по глобальной позиции мыши.

**Проверено**

- 51 тест проходит; скриншот реального окна (не offscreen): «Настройки» и
  подписи видны целиком, кнопки планки и отпечатки времени на месте.
- Копирование бота и пользователя, правка сообщения, отмена/подтверждение
  закрытия, курсоры у краёв и Enter — проверены прогоном сценариев.

    когда в матрицу добавляют навык.

  терминальный `QTextBrowser#skillsView` для окна «Умения».

**Ключевой вывод**

- Индикатор «думает…» нельзя перерисовывать через `BlockUnderCursor` +
  `removeSelectedText`: у последнего абзаца удаление склеивает его с
  предыдущим, точки уезжают в чужую строку. Надёжно — выделить
  `StartOfBlock → EndOfBlock` (без разделителя абзаца) и вызвать `insertHtml`:
  число абзацев не меняется, текст заменяется на месте.
- Абзац индикатора ищем по тексту (`THINKING_TEXT`), а не по номеру блока:
  после вставки ответа нумерация сдвигается.

**Проверено**

- 51 тест проходит; прогон сценария отправки: индикатор появляется, кадры
  сменяются без дублей, после паузы ответ на месте, индикатор исчез, кнопка
  снова активна.
