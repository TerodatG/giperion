# Плагины инструментов агента

Плагины добавляют агенту «Терминала» собственный инструмент. Они
**выключены по умолчанию** и включаются вручную: окно агента →
«Провайдер…» → **«Разрешить плагины инструментов»**.

## Изоляция

- При загрузке читается только **JSON-манифест** — код плагина не
  исполняется.
- Каждый вызов плагина запускается в **отдельном процессе** Python.
- Таймаут — 30 секунд; зависший процесс убивается.
- Падение или исключение плагина не роняет Терминал: агент получает
  ошибку инструмента.
- Вывод плагина подавляется, наружу идёт только JSON-результат.

Это изоляция от падений и зависаний, **но не песочница файловой
системы**: процесс работает с правами пользователя. Включайте только
код, которому доверяете.

## Файлы

`data/agent_tools/` — на каждый плагин два файла:

```
data/agent_tools/my_tool.json   # манифест
data/agent_tools/my_tool.py     # код
```

Манифест:

```json
{
  "name": "my_tool",
  "description": "Короткое описание для модели.",
  "args": {"path": "что означает аргумент"},
  "required": ["path"],
  "risk": "read",
  "module": "my_tool.py",
  "handler": "handler"
}
```

Модуль:

```python
from terminal.core.agent.protocol import ToolResult


def handler(root, args):
    path = args.get("path", "")
    return ToolResult(True, f"Плагин получил путь: {path}")
```

## Правила

- `name` — уникальное, `[a-z][a-z0-9_]{2,30}`, не совпадает со
  встроенными инструментами.
- `args` — словарь «имя → описание», все аргументы строки.
- `required` — обязательные аргументы.
- `risk`: `read` — без подтверждения; `write` и `exec` — с
  подтверждением пользователя.
- `module` — файл `.py` рядом с манифестом.
- `handler` — имя функции в модуле (по умолчанию `handler`).
- Обработчик возвращает `ToolResult(ok, text)`.

После сохранения настроек реестр плагинов перезагружается без
перезапуска приложения.
