# База знаний проекта

Сюда складываются документы, которые агент должен находить по смыслу:
заметки о решениях, выдержки из документации, описания API, чек-листы.

```
python -m tools.knowledge_add docs/architecture.md
python -m tools.knowledge_add --text "Redis не используем: только SQLite" \
  --title "Решение по хранилищу"
```

- Поддерживаются `.md`, `.txt`, `.rst`, `.json`, `.yaml`, `.yml`, `.csv`.
- Размер одного документа — до 200 КБ.
- Файлы получают имя `ГГГГММДД-ЧЧММСС-слаг.md`, исходные имена не
  конфликтуют.
- `knowledge/` не исключён из `semantic_index`, поэтому после добавления
  документ находится через `find_relevant`; для полного векторного
  покрытия запустите `python -m tools.build_semantic_index`.
- Секреты и пароли сюда класть не нужно: индекс и память не шифруются.
